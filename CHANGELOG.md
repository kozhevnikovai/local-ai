# Изменения

## 0.3.1

- `verifyFiles` — проверка SHA-256 уже скачанных моделей; результат запоминается до изменения файла, файл с неверной суммой удаляется. `downloadFiles` проверяет существующие файлы перед загрузкой.
- Пути моделей проверяются с учётом символических ссылок и junction во всех функциях, включая `removeModel` (`modelFilePath`).
- Переадресации при загрузке обрабатываются вручную: каждый переход только на https.
- Пустой список адресов загрузки — ошибка, а не тихий «успех».
- Отмена запроса, ожидающего в очереди, срабатывает сразу; `dispose` дожидается текущего ответа, отклоняет новые и безопасен при повторном вызове.
- `recommend` возвращает `supported: false`, если компьютер ниже требований даже для лёгкой модели.
- `chunkText` с некорректным `maxChars` использует значение по умолчанию.
- README: полный пример запускается без правок.

## 0.3.0

- `chunkText` и `mapReduce` — разбор длинных стенограмм и документов по частям с перекрытием.
- `json`/`text` принимают `{ signal, onText }`: остановка ответа и текст по мере генерации; одновременные вызовы встают в очередь.
- `removeModel` — удаление модели и недокачанного файла.
- Обновлены TypeScript 7, Vitest 5, actions.

## 0.2.0

- Каталог по итогам evals: лёгкая — Qwen3 4B Instruct, мощная — Qwen3 14B. Убраны Gemma 4 E4B и 12B, GigaChat 3.1 Lightning (ниже порога качества).
- Для моделей, кроме Qwen, — шаблон чата, который выбирает node-llama-cpp.
- Workflow models: можно проверить любой список моделей.

## 0.1.0

- Каталог моделей «лёгкая/мощная»: Qwen3 4B Instruct, Gemma 4 E4B, GigaChat 3.1 Lightning, Gemma 4 12B.
- Определение оперативной памяти и видеокарты, рекомендация модели с объяснением.
- Загрузка с докачкой, проверкой места, SHA-256 и запасным зеркалом.
- Запуск через llama.cpp, ответы по JSON-схеме; рассуждения модели отключены (для Qwen — через шаблон).
